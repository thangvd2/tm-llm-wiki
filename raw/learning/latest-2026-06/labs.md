# Labs

Welcome to the Labs. Through use of these materials we hope to give you some practical experience in using the Vault platform.

These labs will provide a hands-on way to learn how to work with Vault Core, and make real API calls as well as create Smart Contracts, and as such are targeted towards engineers.

Each lab will contain a number of exercises, and the resources you’ll need to complete them. If you get stuck try reviewing any linked content - as your question will likely be answered there.

These Labs were designed to be run on any environment, therefore make sure you complete the *Setup* section in each Lab before trying any of the exercises.

Throughout the Labs you’ll be asked to execute cURL commands. Make sure to replace fields inside of chevrons `<like this>`. We also recommend opening a notepad, or blank text document to help with formatting, or reusing requests.

You can also use any third party API software of your choice (we find Postman free and convenient) to draft, send and store the API requests.

In points of the labs you’ll be asked to use a `<UNIQUE-ID>` or `<CURRENT-TIME>`. To make sure your unique ID is unique you can use the `uuidgen` command in the terminal. And to get the current time quickly run: `date -u +"%Y-%m-%dT%H:%M:%SZ"`.
