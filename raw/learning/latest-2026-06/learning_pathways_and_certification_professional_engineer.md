# Vault Core Professional Engineer Pathway

## [](#introduction "Copy link to heading")Introduction

Vault Core Professional Engineer learning pathway equips learners with the knowledge to be able to design, build, test, and deploy Smart Contracts. This learning pathway covers Vault Core architecture concepts and how to apply them when designing financial products, as well as best practice design patterns, data streaming, accounting and end of day.

Vault Core Professional Engineer Certification can be achieved by attending an instructor-led bootcamp or undertaking self learning via the Thought Machine Academy. On completion of the training, learners take the Exam to achieve their Professional Engineer Certification.

## [](#target_audience "Copy link to heading")Target audience

The Professional Engineer Pathway is aimed at developers working with the Vault Core Configuration Layer (Smart Contracts) and/or integrating systems with Vault Core.

## [](#pathway_pre_requisites "Copy link to heading")Pathway Pre-requisites

Each learner must be:

-   Vault Core Fundamentals Certified
    

And should have:

-   A software engineering background that includes:
    
    1.  Intermediate Python knowledge so that they are able to create tests and get the most out of the course
        
    2.  Familiarity with calling APIs via Postman or Curl
        
    3.  Basic kafka knowledge
        
    4.  Basic awareness of kubernetes (purpose, command line tool)
        
    5.  Basic knowledge/awareness of Computer Science fundamentals e.g. system design, data structures, purpose of source version control, testing approaches, Software Development Lifecycle, command line utilities
        
    
-   Intermediate knowledge of banking and accounting
    
-   Experience with requirements analysis and refinement
    

To complete the Lab exercises, learners must have access to a Linux machine with the pre-requistes in the Developer Start Guide installed.

## [](#certification_exams "Copy link to heading")Certification Exams

To achieve Vault Core Professional Engineer Certification, learners need to pass the online exam.

-   Number of questions: 50
    
-   Time: 90 minutes
    
-   Pass Mark: 70%
    
-   Renewal: Certification is valid for 12 months.
    
-   Cost: [See price list](/learning/latest/EN/price_list)
    

Vault Core Professional Engineer Bootcamp attendees will automatically be enrolled for the exam.

Learners who choose the self-learning approach are recommended to complete all the Thought Machine Academy Learning Vault Core Professional Engineer Pathway Courses and 1-2 days revision as preparation for the exam.

Exams can be purchased individually [here](https://ondemand.questionmark.eu/home/612441/catalog) or contact your Thought Machine Representative to purchase multiple exams for your organisation.
