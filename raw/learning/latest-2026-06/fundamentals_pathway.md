# Vault Core Fundamentals

This learning pathway contains six courses which form the basis of the Vault Core Fundamentals Level.

You may take the courses in any order you wish but for a better experience we do recommend completing them in the sequence in which they are presented.

Certification for this level of qualification can be obtained by completing the [Vault Core Fundamentals Certificate Exam](/learning/latest/EN/learning_pathways_and_certification/fundamentals).
