# Lab 3 - Basic Smart Contract Tutorial

This lab contains a series of exercises that will guide you through building a basic Smart Contract in Vault. Each exercise builds upon the previous one, introducing new concepts and functionalities.

By the end of this lab, you will have created a simple Smart Contract that can be deployed and tested within Vault, demonstrating key features such as hooks, parameters, and posting logic.

## [](#prerequisites "Copy link to heading")Prerequisites

Before starting this lab, ensure you have: \* Completed the Vault Core Fundamentals course. \* Access to a Vault instance where you can deploy and test Smart Contracts. \* Familiarity with Python programming, as Smart Contracts are written in a subset of Python. \* Basic understanding of Vault’s architecture and core banking concepts.

## [](#lab_structure "Copy link to heading")Lab Structure

The lab is divided into exercises. Each exercise focuses on a specific aspect of Smart Contract development. You will find instructions, code snippets, and explanations to help you understand each concept.

In the Lab Starter Pack, you will find under `smart_contract_tutorials/library/basic_smart_contract_tutorial` a series of exercise folders that correspond to each exercise found here. Within, you’ll find two files - `deposit.py` and `test.py`. You will be editing the `deposit.py` files to complete each exercise, and running the `test.py` files to verify your work.

Ensure that you’ve also installed the `inception_sdk` and `contracts_api` folders under `smart_contract_tutorials`, have installed the necessary Python libraries found in `requirements.txt`, and set your `PYTHONPATH` to also be the path to `smart_contract_tutorials`.
