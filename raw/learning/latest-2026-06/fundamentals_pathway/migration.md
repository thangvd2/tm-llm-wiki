# Migrations

This course provides a comprehensive guide to migrating core banking data from a legacy system to Vault Core. It covers the challenges and solutions of Vault Core, preparing a robust strategy by defining value drivers and choosing a migration pattern, and implementing practical techniques to de-risk, simplify, and accelerate the migration event.

This course is suitable for the following Vault users:

-   Business Analysts
    
-   Engineers
    
-   Programme Managers
    
-   PMO
    
-   Product Owners
    
-   Solution Architects
    
-   SREs
    
-   Testers
    

## [](#aims_and_objectives "Copy link to heading")Aims and objectives

Having completed this course, you will be able to:

-   Define core banking migration, explore the common challenges involved.
    
-   Introduce how Vault Core’s API-first architecture and tooling mitigate these risks.
    
-   Help determine the optimal migration strategy by identifying value drivers and evaluating the architectural trade-offs of various migration patterns.
    
-   Provide actionable strategies and best practices for reducing risk, simplifying data transformation and load, and accelerating the migration timeline by making informed trade-offs on scope and impact.
