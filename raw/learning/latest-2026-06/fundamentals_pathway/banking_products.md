# Vault Core banking products

This course gives an overview of how Vault Core can be used to drive the creation and behaviour of any banking products.

This course is suitable for the following Vault users:

-   Business Analysts
    
-   Engineers
    
-   Programme Managers
    
-   PMO
    
-   Product Owners
    
-   Solution Architects
    
-   SREs
    
-   Testers
    

## [](#aims_and_objectives "Copy link to heading")Aims and objectives

Having completed this course, you will be able to:

-   Understand how Vault Core separates product builds from other key areas
    
-   Summarise the main characteristics of Smart Contracts
    
-   Get a feel for how you can build products and variations with Thought Machine
