# Vault Core Financial Model

## [](#about_this_course "Copy link to heading")About this course

This course provides an introduction to the key financial principles and posting types behind the Vault Core platform. This includes the accounting model, the balance architecture, and the concept of backdated postings.

This course is suitable for the following Vault users:

-   Business Analysts
    
-   Engineers
    
-   Programme Managers
    
-   PMO
    
-   Product Owners
    
-   Solution Architects
    
-   SREs
    
-   Testers
    

## [](#aims_and_objectives "Copy link to heading")Aims and objectives

Having completed this course, you will be able to:

-   Describe the Vault Core accounting model
    
-   Explain key posting concepts in Vault Core
    
-   Understand how the flexible balance architecture in Vault Core supports our client
