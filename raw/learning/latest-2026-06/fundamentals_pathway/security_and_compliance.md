# Security and Compliance

This course provides an introduction to the Security foundations that Vault Core has been built on.

This course is suitable for the following Vault users:

-   Business Analysts
    
-   Engineers
    
-   Programme Managers
    
-   PMO
    
-   Product Owners
    
-   Solution Architects
    
-   SREs
    
-   Testers
    

## [](#aims_and_objectives "Copy link to heading")Aims and objectives

Having completed this course, you will be able to:

-   State who is responsible for security aspects within Bank hosted and SaaS models.
    
-   Explain what client responsibilities are around privacy and compliance.
    
-   List the foundational security concepts that Vault Core adheres to.
