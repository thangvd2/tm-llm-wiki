# Foundations of Vault Core

This course provides an overview of the Vault Core platform, showcasing the architecture, key benefits and terminology used.

This course is suitable for the following Vault users:

-   Business Analysts
    
-   Engineers
    
-   Programme Managers
    
-   PMO
    
-   Product Owners
    
-   Solution Architects
    
-   SREs
    
-   Testers
    

## [](#aims_and_objectives "Copy link to heading")Aims and objectives

Having completed this course, you will be able to:

-   Explain how Vault supports banks to modernise their core banking platform.
    
-   State the main benefits of the Vault Core platform.
    
-   Explain key features the platform offers.
    
-   Know how to access Vault related documentation.
