# Vault Core Professional Analyst Pathway

## [](#introduction "Copy link to heading")Introduction

Vault Core Professional Analyst learning pathway educates learners on how to gather and write high-quality product requirements using Thought Machine best practices to support the design and build of financial products that run on Vault Core. Delegates will be able to build upon knowledge gained on the Vault Fundamentals course by going deeper into aspects such as best practices for writing smart contracts, data streaming and migration. In addition, leaners will gain an understanding of Vault Core’s capabilities around chart of accounts, end of day processing enabling delegates to consult and contribute to core banking modernisation initiatives.

Vault Core Professional Analyst Certification can be achieved by attending an instructor-led bootcamp or undertaking self learning via the [Thought Machine Academy](https://academy.thoughtmachine.net/). On completion of the training, learners take the Exam to achieve their Professional Analyst Certification.

## [](#target_audience "Copy link to heading")Target audience

The Professional Analyst Pathway is aimed at Business Analysts working on core banking modernisation initiatives implementing financial products on the Vault Core platform or those looking for a better understanding of Vault Core technical concepts.

## [](#pathway_pre_requisites "Copy link to heading")Pathway Pre-requisites

Each learner must be:

-   Vault Core Fundamentals Certified
    

And should have:

-   A Business Analysis background that includes:
    
-   Intermediate knowledge of banking and accounting
    
-   Experience with requirements analysis and refinement
    
-   Basic familiarity with technical concepts and software architecture

## [](#certification_exams "Copy link to heading")Certification Exams

To achieve Vault Core Professional Analyst Certification, learners need to pass the online exam.

-   Number of questions: 50
    
-   Time: 90 minutes
    
-   Pass Mark: 70%
    
-   Renewal: Certification is valid for 12 months.
    
-   Cost: [See price list](/learning/latest/EN/price_list)
    

Vault Core Professional Analyst Bootcamp attendees will automatically be enrolled for the exam.

Learners who choose the self-learning approach are recommended to complete all the Thought Machine Academy Learning Vault Core Professional Analyst Pathway Courses and 1-2 days revision as preparation for the exam.

Exams can be purchased individually [here](https://ondemand.questionmark.eu/home/612441/catalog) or contact your Thought Machine Representative to purchase multiple exams for your organisation.
