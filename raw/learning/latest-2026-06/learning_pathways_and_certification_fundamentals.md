# Vault Core Fundamentals Pathway

Vault Core Fundamentals Pathway is designed to enable all team members to become familiar with Vault Core without any prior experience. It introduces learners to Vault Core architecture and key concepts such as the financial and data model, the basics of Smart Contracts that define financial product behaviour.

You can access the course via the [Thought Machine Academy](https://academy.thoughtmachine.net/learner-dashboard). Upon completion of the training, learners will be required to pass a final exam.

## [](#target_audience "Copy link to heading")Target audience

The Vault Core Fundamental Pathway is aimed at all core banking programme teams members. Thought Machine requires learners to pass their Vault Core Fundamentals exam before undertaking Professional Certifications.

## [](#certification_exams "Copy link to heading")Certification exams

To achieve Vault Core Fundamentals Certification, learners need to pass the online exam.

-   Number of questions: 45
    
-   Time: 60 minutes
    
-   Pass Mark: 85%
    
-   Cost: [See price list](/learning/latest/EN/price_list)
    

Exams can be purchased individually via the [catalogue](https://ondemand.questionmark.eu/home/612441/catalog) or contact your Thought Machine Representative to purchase multiple exams for your organisation.
