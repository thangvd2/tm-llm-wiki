# Vault Core Professional SRE Pathway

## [](#introduction "Copy link to heading")Introduction

Vault Core Professional Site Reliability Engineer (SRE) is aimed at site reliability engineers who will be designing, deploying and supporting Vault Core on a single cloud vendor. This learning pathway provides a comprehensive guide to installing and deploying Vault Core within a single cloud vendor environment. You will learn how to set up the necessary infrastructure, including Kubernetes, load balancers, and other essential components. Additionally, the course covers key observability practices, including logging, monitoring, and alerting, to ensure system reliability and performance as well as investigation and troubleshooting.

Vault Core Professional SRE Certification can be achieved by attending an instructor-led bootcamp or undertaking self learning via the Thought Machine Academy. On completion of the training, learners take the Exam to achieve their Professional SRE Certification.

## [](#target_audience "Copy link to heading")Target audience

The Professional SRE Pathway is aimed at Site Reliability Engineers, DevOps engineers or Cloud Architects.

## [](#pre_requisites "Copy link to heading")Pre-requisites

Each learner must be:

-   Vault Core Fundamentals Certified
    

And should:

-   Be certified in the cloud provider employed on the project - GCP, AWS, Azure or OpenShift
    
-   Be a certified Kubernetes Administrator (CKA)
    

Have familiarity with:

-   PostgreSQL management
    
-   Secrets Management
    
-   Certificates (SSL)
    
-   Ingress Controller
    
-   Grafana

## [](#certification_exams "Copy link to heading")Certification Exams

To achieve Vault Core Professional SRE Certification, learners need to pass the online exam.

-   Number of questions: 50 (including questions from pre-shared case studies )
    
-   Time: 100 minutes
    
-   Pass Mark: 70%
    
-   Renewal: Certification is valid for 24 months.
    
-   Cost: [See price list](/learning/latest/EN/price_list)
    

Vault Core Professional SRE Bootcamp attendees will automatically be enrolled for the exam.

Learners who choose the self-learning approach are recommended to complete all the Thought Machine Academy Learning Vault Core Professional SRE Pathway Courses and 1-2 days revision as preparation for the exam.

Exams can be purchased individually [here](https://ondemand.questionmark.eu/home/612441/catalog) or contact your Thought Machine Representative to purchase multiple exams for your organisation.
