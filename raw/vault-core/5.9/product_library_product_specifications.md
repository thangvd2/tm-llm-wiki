# Product specifications

The product specifications are primarily aimed at both business and technical stakeholders who are interested in using and modifying these products.

They provide a detailed description of the behaviour of each product and its features. This is so that you can understand how it works at a functional level and begin using or modifying it to create a bespoke product.

The product specifications do not contain technical details on how Thought Machine has implemented the features or uses the API to interact with the product - this information is available in the Smart Contract code, the [Vault Core](/vault-core/5-9/EN) and the integration guides.

chat\_bubble
