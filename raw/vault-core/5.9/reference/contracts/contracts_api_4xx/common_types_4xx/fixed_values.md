# Fixed Values

## [](#default_address "Copy link to heading")DEFAULT\_ADDRESS

`DEFAULT_ADDRESS` (`str`) The default address to which Vault makes Postings.

## [](#default_asset "Copy link to heading")DEFAULT\_ASSET

`DEFAULT_ASSET` (`str`) The default asset on all non-custom Postings.

## [](#transaction_reference_field_name "Copy link to heading")TRANSACTION\_REFERENCE\_FIELD\_NAME

`TRANSACTION_REFERENCE_FIELD_NAME` (`str`) If this field is present in the instruction details for a posting instruction, the value will be used as the reference on any corresponding Experience Layer transactions. Available on versions 3.2.0+.
