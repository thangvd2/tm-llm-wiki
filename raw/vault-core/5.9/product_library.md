# Product Library

Thought Machine has designed the Product Library to accelerate clients going live on Vault Core. It provides:

-   a suite of highly-configurable, feature-rich Smart Contracts, built using best practice methods, that you can adopt, reuse, change, and configure
    
-   a full set of tests, including unit tests, simulation tests, and end-to-end tests
    
-   a full set of documentation, including product specifications, common business features, client developer information, and best practice guides
    
-   all the tooling that Thought Machine uses to build, test, and deploy products
    

Learn more about the products, best practices, and download the latest release here.
