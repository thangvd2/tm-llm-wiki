# Edge Functions

Edge Functions are configuration layer components that enhance your integration and implementation capabilities, linking a bank’s internal API gateway and Vault Core API to Vault Core. Use the `edge_api` and `vc_api` libraries to consolidate multiple direct API calls into product-specific, task-based functions that you can execute with a single synchronous API call.
