## [](#clv3_sdk_release_package "Copy link to heading")CLv3 SDK release package

The v1.3.0 version of the Product Library SDK is available for clients who are using Contracts Language version 3 (CLv3). This is equivalent to the SDK shipped with Product Library release version 2023-20. You can optionally download the SHA1 for the v1.3.0 (for CLv3) release package if you wish to verify the `.zip` file.

info

The `library/` folder is still included in order to provide the `library/features/v3/common/common_imports.py` and `supervisor_imports.py` modules. These help facilitate development-time-only imports with Contracts API 3.x and the renderer tool, as Contracts using Contracts API 3.x rely on 'magic' imports.
