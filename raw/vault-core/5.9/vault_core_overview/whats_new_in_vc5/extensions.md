# Extensions

### [](#extensions "Copy link to heading")Extensions

Extensions are optional add-ons available in Vault Core 5. Those include:

-   [**Multiple Processing Groups**](/vault-core/5-9/EN/reference/processing_groups#using_multiple_processing_groups)  
    Multiple Processing Groups allow a bank to achieve financial isolation and separately control the operational behaviour for the Accounts linked to each group on a single instance.
    
-   [**High-volume Accounts**](/vault-core/5-9/EN/reference/accounts/high_volume_accounts)  
    High-volume Accounts are Customer Accounts designed for large-scale operations to manage activity involving substantial throughput of offline postings.
    
-   [**Hibernator**](/additional-product-offerings/latest/EN/hibernator)  
    Hibernator is an automated tool designed to manage non-production Vault Core instances, reducing costs by scaling these instances down according to a schedule during periods of low usage.
    
-   **Premium and Enterprise Support**  
    Contact your Thought Machine representative to understand what options are available to your organisation.
    
-   [**Adjustments**](/vault-core/5-9/EN/reference/adjustments)  
    Adjustments use backdated events to correct an Account’s balances retroactively.
