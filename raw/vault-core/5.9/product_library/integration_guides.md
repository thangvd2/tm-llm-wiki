# Integration guides

Learn about the technical implementation details of the products, to support technical users in using them.

You can use these in conjunction with the information in the Smart Contract code, the [Vault Core](/vault-core/5-9/EN) and the Product Specifications, which provide context about each product. The Product Specifications describe the functional behaviour of the products and their features.
