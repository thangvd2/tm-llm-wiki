# Policies

This is the reference documentation for using policies to enforce access control.

Vault Core currently supports two policy frameworks: [Open Policy Agent](https://www.openpolicyagent.org/) (OPA) Rego policies and legacy policies using actions and data permissions.

chat\_bubble

OPA-based policies will eventually replace the legacy system once feature parity has been achieved.
