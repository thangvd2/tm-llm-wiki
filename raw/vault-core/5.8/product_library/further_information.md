# Further information

## [](#about_the_product_library "Copy link to heading")About the Product Library

### [](#intellectual_property "Copy link to heading")Intellectual property

Although these Product Library templates remain Thought Machine Intellectual Property, we have provided options that allow clients to configure and enhance them so that they can create unique products to offer to their customers.

### [](#scope "Copy link to heading")Scope

Each specification contains information about the functional behaviour of the product from account opening to account closing, and through each of the product’s features.

For each product feature there is a description, the financial calculations involved, related Vault objects, and the most important use cases that we developed against it.

It does not contain technical details how we implemented the features and how the API is used to interact with the product. This information is available in the Smart Contract code, the Vault Portal, and a selection of Integration Guides.

### [](#disclaimer "Copy link to heading")Disclaimer

Thought Machine has designed and built these Product Library product templates to demonstrate the configurability of the financial products and processes within Vault. We intend for you to use each template solely as an aid to accelerate your understanding of Smart Contracts and the platform. Use is at your sole discretion and risk.

The Product Library remains under active development and therefore all content is subject to regular iterative change. Thought Machine endeavours to respond in a timely manner to any issues or queries raised in relation to the products in the Product Library.
