# Workflow instantiation configuration

In order to use a workflow, banks must configure the resource that each workflow is instantiated on using the Operations Dashboard.

The following is a mapping from the workflows to their associated resource.

 
| Workflow definition ID | Instantiation configuration |
| --- | --- |
| 
`LOAN_APPLICATION`

 | 

Customer

 |
| 

`LOAN_REPAYMENT_HOLIDAY_APPLICATION`

 | 

Customer account

 |
| 

`LOAN_MARK_DELINQUENT`

 | 

Auto-instantiated

 |
