# Code samples

Thought Machine has designed this library of example Edge Functions to help clients accelerate the integration of Vault Core into their infrastructure. It provides a collection of example pre-built Edge functions that model common business journeys, simplifying the orchestration of API calls to Vault Core. By using Edge Functions, clients can avoid the need to build integration services, streamlining their implementation process. To learn more about the Vault Edge Functions capability, see [Edge Functions tutorials](/vault-core/5-8/EN/reference/edge_functions).

## [](#features "Copy link to heading")Features

Each Edge Function in the library is accompanied by:

-   a code sample of the Edge Function along with unit tests
    
-   comprehensive documentation
    
-   a CLU package which you can optionally use to import the samples for use in your environment using the [Configuration Utility Layer](/vault-core/5-8/EN/environment_and_installation/infrastructure_docs/configuration_layer_utility_user_guide) (CLU), to help you get started quickly and efficiently
    

## [](#active_development_and_expansion "Copy link to heading")Active development and expansion

The Edge Functions examples library will grow over time as Thought Machine adds new Edge Functions and introduces additional capabilities to Edge Functions. It will expand to include templates that showcase and leverage this new functionality.
