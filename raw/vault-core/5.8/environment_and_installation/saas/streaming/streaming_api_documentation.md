# Streaming API documentation

SaaS

## [](#streaming_api_documentation_for_vault_core "Copy link to heading")Streaming API documentation for Vault Core

You can use the Vault Core Streaming API to capture and analyse Vault Core business events, such as Balances, Accounts and Schedule execution.

To learn more about the Streaming APIs that are available in the version of Vault Core that is running in your environment, visit the following sections:

-   [Using the Streaming APIs](/vault-core/5-8/EN/api/overview#using_the_streaming_apis) - general operational information
    
-   [API overview](/vault-core/5-8/EN/api/overview) - a quick introduction to the different REST APIs in Vault Core and which have an associated Streaming API
    
-   [API reference](/vault-core/5-8/EN/api/) - choose a Vault Core API to access its dedicated Streaming API section
