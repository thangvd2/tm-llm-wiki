# Streaming

You can use the Kafka-based Core Streaming API to capture and analyse business events that occur in Vault Core, such as Balances, Accounts and Schedule execution.

Here, you can learn about the data streaming solutions available to use with Vault Core SaaS. For Streaming API reference information, see the following areas:

-   [Using the Streaming APIs](/vault-core/5-8/EN/api/overview#using_the_streaming_apis) - general operational information
    
-   [API overview](/vault-core/5-8/EN/api/overview) - learn about Vault Core REST APIs and associated Streaming APIs
    
-   [API reference](/vault-core/5-8/EN/api/) - choose an API to access its dedicated Streaming API section
