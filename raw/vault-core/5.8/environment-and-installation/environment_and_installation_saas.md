# Vault Core SaaS

Welcome to the onboarding and support documentation for the SaaS hosting model of Vault Core. Use these guides to learn the key details you need about Vault Core SaaS and how to get started.

-   Get an overview of Vault Core SaaS and guides to onboarding, getting started with a new environment, observability, and monitoring of the Vault Core APIs exposed in Vault Core SaaS
    
-   Learn how to use the Vault Core product and its APIs using the Vault Core documentation
