# Workflows

This is the reference documentation for Workflows and Tickets within Vault.

chat\_bubble

Vault Workflows is deprecated as of Vault release 4.6.0, and will be removed no earlier than release 7.0.0.

error

Do not change `ops.bank_name` in `values.yaml` after installing Vault Core. Any existing legacy workflows using the initial `ops.bank_name` value will be unusable, and attempts to upgrade Vault Core will encounter errors.
