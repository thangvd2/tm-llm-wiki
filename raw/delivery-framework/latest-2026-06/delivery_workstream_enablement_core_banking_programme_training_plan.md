# Core Banking Programme Training Plan

## [](#purpose "Copy link to heading")Purpose

This step synthesises the skills and training required for the programme team, established through the Activity: Skills capability assessment, into a training plan. This ensures the programme has a roadmap to achieve the required skills and experience it needs, and to ensure its success at relevant points along the implementation journey.

## [](#predecessor_activities "Copy link to heading")Predecessor Activities

N/A

## [](#guidance "Copy link to heading")Guidance

The planning should be based on the skills capability assessment and the Vault training needs gap analysis, which are pre-requisites to this activity. Other things to take into account include:

-   Any standard courses available within the team’s organisation.
    
-   Any courses provided by vendors not engaged on the programme, e.g. Python courses, cloud provider training.
    
-   Courses, bootcamps and certifications provided by vendors associated with the programme, e.g. Thought Machine Vault and various cloud providers.
    
-   All course prerequisites or dependencies.
    
-   The programme team’s availability, and its existing capabilities.
    
-   The programme delivery plan.
    

This activity will flag which existing courses need to be taken, and when. It might also guide the development of new courses and training materials.
