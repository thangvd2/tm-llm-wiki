# Existing Infrastructure Impact Assessment

## [](#purpose "Copy link to heading")Purpose

This activity assesses the potential consequences of any changes that will need to be made to existing infrastructure. Due to their nature, core banking systems are usually woven tightly into the existing fabric of an organisation, so the design must also consider modifications to connectivity, decommissioning redundant systems, as well provisioning new infrastructure.

A key deliverable from the analysis is a report that outlines the impact of proposed changes that highlights key system dependencies and risks. Additionally, the report should provide recommendations for minimising disruption and ensuring a smooth transition through proper planning and upfront design work.

Failure to assess potential changes to an existing infrastructure may result in unexpected downtime, loss of data, or system instability which will impact the reliability and effectiveness of the core banking systems overall.
