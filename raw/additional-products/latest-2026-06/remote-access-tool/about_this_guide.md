# About this guide

This guide gives you the required technical content to understand, deploy and operate Remote Access Tool, a remote access tool by Thought Machine.

## [](#background "Copy link to heading")Background

Thought Machine has developed Remote Access Tool to allow limited, read-only (by default), access from Thought Machine offices to bank-hosted Vault Core environments. This tool aims to improve customer experience by helping reduce incident mitigation times, avoiding the back and forth of the Jira Service Desk approach.

Specifically, Thought Machine engineers are able to access a limited set of endpoints on the cluster with security controls in place to prevent broader access. With access to these endpoints, a Thought Machine engineer can perform much of the initial diagnostics and information gathering remotely, thus helping to improve Thought Machine’s incident response.

## [](#audience "Copy link to heading")Audience

This guide is intended for those involved with:

-   Installation of Thought Machine software to a bank-hosted environment
    
-   Operation of Vault and incident diagnostics
    
-   Ensuring business compliance as it pertains to the Vault environment
