# Edge Functions

chat\_bubble

This section of our documentation is dedicated to Edge Functions on Vault Bridge. If you use Edge Functions within Vault Core, refer to the Vault Core [Edge Functions documentation](/vault-core/latest-5-x/EN/reference/edge_functions).

Edge Functions in Vault Bridge includes multiple new capabilities such as third-party and Vault Payment API support, and enables separation of compute resources for Edge Functions workloads outside of Vault Core clusters.

Edge Functions are a service within the Vault Bridge platform that enhance your integration capabilities by linking your internal systems with Vault services and third-party APIs. Use the `edge_api` and `vc_api` libraries to consolidate multiple API calls into product-specific, task-based functions that can be executed with a single synchronous API call.
