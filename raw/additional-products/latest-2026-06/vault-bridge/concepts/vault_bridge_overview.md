# Vault Bridge overview

> **Our vision is to provide a delightful, self-service platform that enables  
> the world’s financial institutions to be able to launch an entire financial product.**

Vault Bridge is the integration layer for the broader Vault Platform. Vault Bridge provides a suite of Apps, integrations, and additional banking capabilities that enables an organisation to:

-   Access an extensive library of Apps, all via the Vault Bridge Console
    
-   Benefit from a unified experience across all Thought Machine products
    
-   Easily manage their Vault Core environment
    
-   Adopt new Apps, and deploy new version upgrades without requiring a full core banking system update
    
-   Make new App development, deployment, and installation quick and easy
    

Vault Bridge complements Vault Core and Vault Payments. It is deployed outside of the Core banking system to enable an organisation to be able to switch on entirely new functionality, at runtime, quickly and safely, without needing to upgrade or touch the underlying Core Banking System.

Today, Vault Bridge consists of the following key features:

-   [Console](/additional-product-offerings/latest/EN/vault-bridge/concepts/console)
    
-   [App Library](/additional-product-offerings/latest/EN/vault-bridge/applications/)
    
-   [Integrations](/additional-product-offerings/latest/EN/vault-bridge/concepts/integrations)
