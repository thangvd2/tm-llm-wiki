# Edge Functions SDK reference

The Edge Functions SDK comprises two libraries:

-   `vc_api` - this library is specific to Vault Core and provides a way to interface with Vault Core’s public APIs
    
-   `edge_api` - this library is independent from Vault Core API versions and exposes functions and classes required to author or test Edge Functions
    

These two libraries contain all the functionality necessary to structure Edge Functions to call Vault Core endpoints in an intuitive way.
