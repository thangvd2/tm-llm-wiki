# Istio

Vault Bridge requires the installation and configuration of a service mesh – specifically Istio – to function properly. If you are installing Vault Bridge on a cluster that has already been provisioned for Vault Core, and thus has Istio already installed, you don’t have to do anything more. However, if you are installing Vault Bridge on a new cluster you will have to follow the [Istio installation guide](/vault-core/latest/EN/environment_and_installation/infrastructure_docs/vault_cloud_infrastructure/configuring_istio_service_mesh_with_vault) found in Vault Core’s documentation.

lightbulb

The guide linked above refers to Vault Core, however everything also applies to Vault Bridge.
