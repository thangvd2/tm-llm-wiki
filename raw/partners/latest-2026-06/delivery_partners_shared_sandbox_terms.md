# Public Shared Sandbox Terms

## [](#public_shared_sandbox "Copy link to heading")Public Shared Sandbox

The Public Sandbox is a read-write instance of Vault Core for learners who are looking to put into practice the skills they have learnt from our Enablement training.

This is a benefit made available to partners who already have a number of trained and certified practitioners at Fundamentals level. If you would like to access, please reach out to your Partner Manager to discuss if you meet the criteria requirements.

**Additional information:**

Please note the Public Sandbox is accessible by multiple partners.

-   Any and all code developed in the Public Sandbox is fully owned by Thought Machine. The instance will be wiped on a regular basis (~ every 5 weeks) to ensure a clean environment is provided for all learners.
    
-   Any work can be saved as a Configuration Layer pack and deployed again once the wipe has completed. There is detailed guidance on the Configuration Layer and the Configuration Layer Utility on the Enablement Portal and in the Documentation Hub.
    
-   This sandbox will be upgraded 5 working days after a new release of Vault Core to the previous minor release of Vault Core, for example when V5.2 is available the sandbox will be upgraded to V5.1
