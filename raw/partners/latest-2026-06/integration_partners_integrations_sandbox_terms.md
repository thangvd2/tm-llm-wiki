# Integrations Sandbox Terms

## [](#integrations_sandbox_read_write "Copy link to heading")Integrations sandbox (Read-Write)

The Integrations Sandbox is a read-write instance of Vault Core for technology vendors who are looking to build an integration to Vault Core. Primarily it is for vendors who will need to make a posting to Vault Core to prove out a key use case.

This is a benefit made available to selected ISV partners who need to demonstrate a key capability area. If you meet this criteria please reach out to your Partner Manager to request access. The form for requesting access to the sandbox can be found here

N.B.

Please note the Integration Sandbox is accessible by multiple partners.

-   Any and all middleware developed by the partner is the partner’s IP to maintain and support. Note that multiple vendors can view postings made into the Integrations Sandbox. As such, smart contract functionality should be disabled from the sandbox, unless specifically requested and agreed.
    
-   As such, partners must acknowledge and agree that by submitting any Posted Content and/or Partner Middleware into the TM Integration Sandbox Environment, this is done so at your own risk and that Thought Machine shall not be liable for any Losses that result from Environment Content being submitted or otherwise made accessible in the TM Integration Sandbox Environment.
    
-   This sandbox will be upgraded 5 working days after a new release of Vault Core to the previous minor release, for example when V5.2 is available the sandbox will be upgraded to V5.1
