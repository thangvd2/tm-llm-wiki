# Example

warning

Example configuration packs are not intended for processing real payments but serve as an educational tool to help understand the platform’s functionality.

These packs are particularly useful for:

-   **Learning the Basics**: Get hands-on experience with Vault Payments without the complexity of real-world financial transactions.
    
-   **Exploring Payment Flows**: Understand how Vault Payments processes different payments from different scheme families.
    
-   **Testing Configurability**: Experiment with the platform’s flexible configuration options to see how payment processing logic can be tailored to specific needs.
    
-   **Simulating Payment Journeys**: Use the sandbox environment to test different payment scenarios and observe how Vault Payments responds. These example configuration packs are best used in conjunction with the Vault Payments Sandbox, which provides a safe and controlled environment for testing and evaluation.
