# Submit an outbound instant payment

The aim of this tutorial is to construct a request to submit an outbound payment to Vault Payment’s instant payment scheme simulator and use the Vault Payments app to discover the eventual status of the payment.

## [](#submit_instruction_to_tminstant_scheme_simulator "Copy link to heading")Submit Instruction to TMInstant scheme simulator

In this tutorial we will construct and submit an `Instruction` to initiate an outbound payment. This tutorial will make use of Thought Machine’s Credit Transfer Simulator and the "TMInstant" demo scheme. "TMInstant" will act as the scheme - however the tutorial is representative of how outbound instant payments would be submitted to modern ISO20022 based instant payment schemes.

For outbound instant payments it is the debtor account that is recognised by Vault Payments. The creditor account is held by another financial institution. The request below will create a FIToFICustomerCreditTransfer Instruction to send 25 euros from a debtor account, that is automatically provisioned for users of the sandbox instance, with the IBAN `FR9120051010050500013M02505` to an external creditor account with the IBAN `IBAN_EXTERNAL_TO_VAULT_PAYMENTS`.

You can find more information on the resources that are automatically provisioned for sandbox users [here](/vault-payments/latest/EN/introduction_to_vault_payments/sandbox_quick_start#provided_resources).

First we need to create an `Instruction` using the [/api/v1/instructions:initiate POST endpoint](/vault-payments/latest/EN/api/payments_api#instructions).

When using the `:initiate` endpoint, the response will look like this:

Please copy the `id` of the Instruction in this response - it will be used in step 2 of this tutorial.

The initiate Instruction endpoint is asynchronous. Structurally valid Instructions are assigned a `processing_status` of `IN_PROGRESS` and processing of the Instruction begins.

The processing of this instruction involved the following steps:

-   The Instruction is confirmed to be valid for the TM Instant payment system. For example, the amount must be less than 30 - however any currency can be used. - Vault Payments reads the value of `debtor_account.identification.iban` in the Instruction request and looks for a Payment Instrument that matches it. In this request, Vault Payments searches for a Payment Instrument where `routing_information.instrument_identifier` is equal to `FR9120051010050500013M02505`. - Vault Payments verifies that both the Payment Instrument and associated Account Link are able to process the submitted Instruction. - Before the payment is submitted to the TMInstant scheme - funds need to be ring-fenced on the debtor’s account. Outbound authorisation postings are submitted to Vault Core. - Finally, provided that the steps above succeeded, the Instruction is submitted to the TMInstant scheme simulator for processing.
    

## [](#tracking_the_status_of_the_payment "Copy link to heading")Tracking the status of the payment

The Instruction (A) that was created in the previous step has now been submitted to the scheme simulator for Vault Payment’s fictitious scheme - TMInstant. When receiving this Instruction, the default behaviour of TMInstant is to accept the payment. The simulator constructs and sends a new Instruction (B) that acts as a confirmation to Vault Payments that A was accepted by the scheme and the receiving bank. Instruction B has a payload type of `FIToFIPaymentStatusReport` - Vault Payment’s representation of a pacs.002 from the ISO 20022 messaging standard.

You can track the overall status of the payment by using the Vault Payments app.

1.  Access the Vault Payments App using a browser by clicking the following URL: [https://sandbox.payments.tmachine.io](https://sandbox.payments.tmachine.io) and login.
    
2.  Select `Payments` and then `Search` on the navigation bar to navigate to the search page. Paste the ID of the Instruction that you made a note of in the previous step into the text box below the `Search for anything` label. Click on the magnifying glass or press enter to be taken to the payment details page.
    
3.  The status of the Payment (comprised of Instruction A and B) is displayed at the top of details page as 'Settled'.
    

Both Instructions are displayed in the payment detail view. By scrolling down to the Instruction titled `Payment status report` you will be able to inspect the details of the Instruction that was generated by the TMInstant scheme simulator.

For more information on TMInstant flows and the capabilities of the scheme simulator please see [TMInstant scheme](/vault-payments/latest/EN/account_to_account/tminstant_a2a).
