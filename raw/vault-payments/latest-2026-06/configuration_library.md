# Configuration Library

The Configuration Library for Vault Payments is a collection of pre-built configuration resources designed to accelerate the deployment and customization of payment processing within Vault Payments. It provides a structured set of flows, rules, parameters, and integrations that enable financial institutions to efficiently configure and manage payment lifecycles across different payment schemes.

Key Features:

-   **Pre-configured Instruction Flows**: A set of predefined flows that dictate the sequence of operations for processing payments, reducing the need for extensive custom development.
    
-   **Rules and Parameters**: Configurable rules and parameters that allow institutions to define payment processing logic without modifying underlying code.
    
-   **Scheme-Specific Resources**: Configuration packs tailored for various payment schemes, ensuring compliance with industry standards.
    
-   **Continuously Updated**: The configuration library is regularly updated to reflect platform improvements and payment system rule changes.
    
-   **Simplified Management via CLU**: The Configuration Layer Utility (CLU) provides a user-friendly interface for managing and applying configuration resources.
    

The Configuration Library is designed to be flexible and modular, allowing financial institutions to adopt, modify, and extend configurations to meet their specific payment processing needs.

## [](#production_grade "Copy link to heading")Production Grade

The Production Grade section of the Configuration Library provides a curated set of configuration packs designed and maintained by Thought Machine.

These packs enable clients to accelerate their go-live process by offering pre-configured, production grade setups for payment systems from across the global.

### [](#quality "Copy link to heading")Quality

Production Grade Payments Configuration Library packs are tested against the Vault Payments Platform and are designed for use in production environments.

We will make reasonable efforts, based on information available to us, to keep the Payments Configuration Library configuration packs up to date with the relevant payment system rules.
